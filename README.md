Q-SHIELD is the code and data behind the paper Q-SHIELD: Post-Quantum Authenticated Key Establishment and Misbehavior Detection for V2X Networks. It contains a three-message vehicle-to-RSU handshake with a fresh ML-KEM-768 key per session and ML-DSA-65 signatures, benchmarked against ECDHE-ECDSA and ECDHE-RSA-3072. It also includes an exact airtime model for signed beacons on IEEE 802.11p, and a random-forest plus XGBoost misbehavior detector evaluated on the VeReMi Extension dataset.
